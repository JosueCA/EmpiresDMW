# Empires Dawn Of The Modern World

# Modern systems compatibility
- Extract dxvk-3.0.2.tar.gz or download the lastest version of DXVK https://github.com/doitsujin/DXVK

- Copy these dll files to game root directory
dxvk-3.0.2/x32/d3d8.dll
dxvk-3.0.2/x32/d3d9.dll
dxvk-3.0.2/x32/d3d10core.dll
dxvk-3.0.2/x32/d3d11.dll
dxvk-3.0.2/x32/dxgi.dll

# Additional system compatibility

- Copy these files to game root directory
Empires_DMW.exe
hd.dll
hd.ini

- Change parameters in hd.ini
